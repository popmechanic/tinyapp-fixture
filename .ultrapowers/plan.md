# Tags with a tag filter — a tags box on every row, one chip per tag in use, and the count line saying how many are tagged

**Grammar:** claims-v1

**Claim:** When I type a few tags into a todo's row, the filter bar grows one chip for each tag anyone is using, clicking a chip shows me only the todos carrying that tag, and the count line tells me how many todos are tagged. (elicited)
**Summary:** This gives every todo a small tags box in its row, so a todo can carry words like home or urgent beside its text, and it turns those words into chips in the filter bar — one per tag in use — that narrow the list to the todos wearing that tag, with the count line saying how many todos are tagged at all. It exists because the fixture's filter bar can only split todos by done and not done, and a real list needs one more axis that the person chooses for themselves. After this run a todo carries the tags typed into its row, the chips appear and disappear as tags come into and go out of use, and the synced store that keeps every browser in step carries the tags exactly as it carries everything else.

**Goal:** popmechanic/tinyapp-fixture gains tags: a `tags` string cell on every todo (the tags joined by `,`, absent when there are none), a `tag` store value naming the chosen tag filter, `client/src/todoTags.ts` as the one spelling of those two strings and of the readings over them (`tagsInUse`, `countTagged`, `activeTag`, `hasTag`), a `TagsInput` text box on every row named `Tags for <todo>`, one chip per tag in use inside `#filterBar` named `Tag <tag>` whose click filters the list — and whose second click clears the filter — and a `#taggedCount` element beside `#doneCount` reading `<n> tagged`. The synced shape stays exactly as it is: the same `MergeableStore`, the same `WsSynchronizer` and SQLite persister in `client/src/Store.tsx`, untouched. Three contracts over one shared literal; the feature was picked by the operator on 2026-09-17.

**Tech Stack:** Bun 1.4 + TypeScript 6 + TinyBase 9.7 (`tinybase/with-schemas`, a `MergeableStore` under `TABLES_SCHEMA` and `VALUES_SCHEMA`), React 19 (`tinybase/ui-react/with-schemas` hooks re-exported from `client/src/Store.tsx`); Tailwind v4 + shadcn/ui (`@base-ui/react` primitives under `client/src/components/ui/`, `@shadcn/lint`'s six rules as `bun run lint:ui`); the `tinyapp-exam` state exams under `tests/state-exams/` over raw CDP against `/headless-shell/headless-shell` on the fleet image, seeds and expected states under `state-exams/`; `bun run typecheck`, `bun run lint:state`, `bun run lint:ui`, `bun test`.
